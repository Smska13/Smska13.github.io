Политика конфиденциальности

Обновлено 15 октября 2026 года.

Second Brain Oleg: личный Telegram-ассистент владельца. Эта политика описывает обработку данных приложением и его справочным сайтом.

Какие данные нужны приложению

  • Сообщения, которые владелец отправляет боту: текст, голос и расшифровки.
  • Заметки, задачи, выбранные разделы и показатели целей.
  • Данные событий подключённых Google Календарей: названия, описания, даты, время и идентификаторы, необходимые для работы с расписанием.
  • Идентификаторы Telegram для ограничения доступа и служебные данные доставки сообщений.
  • OAuth-разрешения и токены, позволяющие обращаться к Google Calendar API.

Для чего используются данные

Приложение сохраняет заметки, ведёт задачи, показывает расписание, создаёт, изменяет, переносит и удаляет выбранные события, отправляет обзоры и напоминания. В режиме Codex выбранный контекст помогает отвечать на вопросы владельца.

Данные Google используются для этих функций по разрешению владельца. Приложение не продаёт данные и не использует их для рекламы.

Где хранятся данные

Текстовые записи и параметры задач хранятся в базе и файлах на личном сервере владельца. Заметки синхронизируются с его компьютером. Приложение хранит исходное аудио временно, на время обработки; постоянный аудиоархив приложение не ведёт. Это не определяет сроки хранения сообщений самим Telegram.

Резервные копии хранятся на сервере и компьютере. Серверные копии, отправляемые в приватный GitHub-репозиторий, зашифрованы. OAuth-токены и ключи хранятся отдельно от публичного кода и этого сайта.

Какие сервисы участвуют в обработке

Telegram доставляет сообщения; Google предоставляет Calendar API; GitHub хранит публичный справочный сайт и зашифрованные резервные копии в отдельном приватном репозитории. При использовании режима Codex вопрос и необходимый контекст передаются OpenAI для подготовки ответа. Для этих сервисов также действуют их собственные условия и политики обработки данных.

Отзыв доступа и удаление

Доступ к Google можно отозвать на странице подключений Google-аккаунта. После отзыва приложение не сможет обращаться к календарю с отозванным разрешением.

Отзыв разрешения не удаляет уже сохранённые заметки и резервные копии. Отмена записи в боте сохраняет её исходный текст в архиве. Полное удаление из базы, файлов, истории и резервных копий выполняется отдельно владельцем установки.

Что собирает этот сайт

На сайте нет форм, аналитики, рекламных трекеров и скриптов. Сайт не запрашивает доступ к календарю и не принимает токены. GitHub Pages может сохранять технические журналы посещений, включая IP-адрес, по политике GitHub.
